# Luma 0.7.0 升级说明

## 项目内多任务
- 同一项目下可创建多个任务／会话，共享项目目录；聊天历史、工具队列、审批、变更追踪分别保存。
- 侧栏按项目分组，可折叠、新建任务；显示就绪、执行中、等待审批、已完成等状态，支持筛选。
- 任务仍支持重命名、搜索、置顶、归档与删除；删除只清除选中会话，不删除项目文件或其他任务。删除原主会话后，其余任务仍可使用。
- 项目默认扩展在该项目任务间共享，新任务自动带入可移除标签。不可用默认项会提示并跳过。
- 同一次应用运行中，切换任务保留各自未发送的文本、附件和扩展标签；草稿未写入磁盘，退出后不保证保留。
- “独立聊天”创建独立聊天目录；项目标题旁的 + 或“项目内新任务”使用当前项目目录。

## 兼容旧数据
旧主会话继续读取原文件，不搬迁或覆盖历史。新会话使用独立 conversation-ID 文件。首次写入新版本项目索引前，会保存 backups/pre-0.7.0-projects.json。模型、连接与模式设置仍为应用级。

## 帮助与扩展兼容
- 帮助菜单新增“扩展开发指南”，打包内置、离线阅读，支持原有菜单键盘导航。
- 11 个预置插件更新为 1.1.0；保留原最低 Luma 版本，上限更新为 0.7.99，实际验证版本为 0.7.0。详情页分别展示声明支持范围和实际验证版本。
- 检查并更新 5 个独立预置 Skill、4 个插件附带 Skill 的兼容信息和多任务工作说明。Skill 列表展示范围；不兼容的 Skill 在诊断中说明原因。
- 安装后启动时，只更新未修改过的旧预置 Skill；用户编辑过的内容保留。第三方插件显式声明最高 0.6.99 的，仍会提示不兼容，需要作者更新。
- 插件 API 保持 1。原配置、信任机制与数量限制保持不变：安装 100、启用代码插件 20、每轮工具插件 12、Skill 8。

## 执行边界
本版是多会话管理，执行仍串行，不提供并行改文件或自动任务队列。同项目其他任务待审批时，新的执行和回滚会被阻止。项目文件共享，变更回滚仍会检查文件现状；会话隔离不等于文件副本或 Git worktree。

## 安装
从系统托盘退出旧版，再覆盖安装。预置插件包内容变化会撤销旧启用／信任状态，请升级后重新启用；原声明式配置保留。不要同时用旧版访问已升级的数据目录。安装包未签名。


## 验证结果
166 项自动测试通过，2 项因 Windows 环境限制跳过。新增测试覆盖旧会话保留、新任务磁盘隔离、工具与审批归属、跨会话错误审批拒绝、重置/删除互不影响、共享文件回滚保护、项目默认扩展、归档、搜索、11 个预置包及9个 Skill兼容性、未修改旧 Skill 升级与用户编辑保留。

隔离界面验证通过项目内新建、独立回复、主会话隔离、任务状态筛选、草稿切换、帮助指南和插件详情范围；无浏览器脚本错误。安装组件测试通过默认11插件+5独立Skill、自定义选择、不安装扩展和升级保留用户Skill。最终安装包内程序、界面和全部预置包与源文件逐项一致。

冻结程序自检通过 API、插件子进程、预置工具、搜索和附件依赖；凭据加密自检仍报告此前环境错误 2，本版未修改凭据机制。未连接真实 LAN 模型，未覆盖安装用户当前程序。
