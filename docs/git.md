# Git 本地版本管理

## Git 本地版本管理（0.7.7）

从左侧分支图标打开 Git。未选择项目、未检测到 Git、未初始化仓库及缺少提交身份会分别提供引导。环境中可指定 git.exe 完整路径或留空恢复自动检测，不随安装包捆绑 Git。

文件分为未暂存、未跟踪、已暂存三组。点击查看逐行差异或修改前后对照，可单个或批量暂存/取消暂存。填写提交说明并确认，只提交已暂存内容；生成说明将暂存差异发送给当前模型，由你检查后决定是否提交。失败保留说明。

提交身份默认仅用于当前仓库；全局设置必须主动勾选。历史展示最近 40 次提交，点击提交与文件查看差异。本地分支支持创建与切换；存在未提交修改时不切换。冲突和未完成合并需在外部 Git 工具处理。

项目若属于上级仓库，会展示实际根目录与整个仓库的变更。初始化不自动提交/上传，不覆盖已有 .gitignore。基础忽略规则只作起点，请按项目情况补充。

文件审阅的“保留”不是 Git 提交，“撤销”不是 Git 取消暂存。本版不提供 Push/Pull、分支删除、强制重置或自动提交。Git 自身的提交钩子和签名设置仍生效，错误会展示，超过 45 秒提示超时后需刷新检查状态。
