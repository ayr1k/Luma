# Luma 0.5.6

## 更宽松、可恢复的执行流程

Work 模式连续无工具回复上限默认由 3 次调整为 6 次；参数设置可调整为 3–20 次。默认第三次仅提醒模型执行下一步或明确询问信息，不强制创建文件。

达到上限后进入“已暂停”，保留上下文、工具记录和文件修改。点击“继续执行”重置无工具计数，继续当前任务，不重放已执行的工具；点击“补充要求”在输入框回答后发送；也可以“停止任务”。补充要求按新一轮输入处理，重置步骤预算。

相似回复仅提示，不提前终止。明确带询问标记或符合保守提问规则的回复会暂停等待用户；识别不是完美的，可以手动继续。Chat 和 Plan 原有正常文字回答结束行为不变。

总步骤上限仍保留，到达上限也暂停。此时点击继续，明确开启新的步骤预算。终端审批机制、流式中断保护和 workspace sandbox 不变。

## 思考内容与兼容参数

接收模型/网关返回的独立 reasoning_content 或 thinking 字符串，以可折叠区域显示并保存，不混入正文。不返回该字段的模型不会凭空显示思考内容；不代表模型内部没有推理。正文中的 <think> 标签及非字符串思考块暂未专门适配。

参数设置新增思考强度：模型默认、关闭、低、中、高。非默认值通过 reasoning_effort 发送，需要实际模型与 LiteLLM 路由支持；不支持时可能拒绝请求，请恢复默认。此版本提供手动兼容配置，尚未自动检测每个模型支持的档位；设置目前全局应用，不按模型单独保存。默认不额外发送思考参数，也不会自动重试被拒绝的请求。

## 升级

先在系统托盘右键“退出 Luma”，再运行 Luma-Setup-0.5.6.exe 覆盖升级。仅关闭窗口会驻留后台。已有对话和配置保留；旧版已经失败的任务可通过补充消息或编辑提问重新开始，不自动迁移为暂停。

## 验证

87 项测试通过，2 项受 Windows 沙箱限制跳过。覆盖四次规划后执行、六次后暂停恢复、询问与补充、自定义上限、总步骤预算、恢复不重放操作、恢复鉴权及真实 SDK 模拟流中的思考字段和参数。界面验证暂停和继续执行、参数配置。

未对真实 LAN 主机的具体模型验证思考参数支持程度。冻结自检与安装包内容校验完成；Windows 凭据加密自检仍有旧版相同的沙箱系统错误 2。安装包未代码签名。
