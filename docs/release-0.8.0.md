# Luma 0.8.0 · SoHo

0.8.x 的版本代号为 SoHo，来自纽约地名。同一中版本系列共用代号；0.9.x、1.0.x、1.1.x 等在首次发布时各选一个纽约地名。代号不改变版本比较与 LTS 政策。

## Git 与更新

- 从仓库地址克隆到新文件夹，并自动添加为项目。支持 HTTPS、SSH 和本地绝对路径；已有目录不覆盖，子模块不自动初始化。失败保留临时目录并显示位置。
- Git 操作记录保留最近 50 次成功或失败与时间，隐藏地址中的凭据，方便排查同步问题。继续提供认证、网络、历史分叉和超时指引。
- 帮助新增“检查更新”，关注 Latest 或 LTS，后台查询 GitHub 公开 Release；启动后每天最多自动检查一次，可关闭。检查失败保留上次结果，不阻塞对话初始化。
- 打开发布页后由用户下载统一安装包，安装时选择渠道；不会自动安装或切换渠道。

## 扩展管理与预置兼容修复

- 安装前展示来源、现有版本、替换版本、权限和支持范围。详情页展示安装目录与最近可回退版本。
- 插件更新保留配置及插件数据；保留最近 5 个可操作的历史版本，支持回退最近版本。不兼容当前主程序的历史版本不允许回退；回退后不会被同一个预置包立即覆盖。
- 安装、更新、回退后默认禁用，代码插件需要重新确认信任。代码插件仍不是操作系统沙箱，拥有当前用户权限。
- 修复旧包不兼容导致预置升级被提前阻止；统一使用真实主程序版本检查兼容性，不再使用遗留的 0.7.3 常量。
- 按完整内容校验识别历史预置包，修复旧来源标记和注册表元数据。保留用户修改、主动卸载记录与自定义同名包，不要求清缓存或卸载应用。
- 11 个预置插件、5 个独立 Skill 与 4 个插件 Skill 更新为 1.2.0，声明支持上限 0.8.99，实际验证版本 0.8.0。
- 扩展中心提供“检查预置更新”及“升级兼容检查”。升级前备份关键 JSON 设置，检查会话可读性；这不是完整数据备份，也不会改写历史会话。

## 安装与 LTS

唯一安装包 Luma-Setup-0.8.0.exe；Latest 0.8.0 SoHo / LTS 0.7.2 可选。LTS 使用自己的程序与原版预置扩展，不混用 Latest 新包。覆盖安装前从托盘退出程序。

历史插件文件若被用户修改，会保留并提示手动重新导入。更新后的插件请在扩展中心重新启用。Latest 与 LTS 共用用户数据；切换渠道前仍应备份数据，旧版不兼容的新插件会被禁用。0.8.0 仍属于 0 系列，不新增 LTS 锚点。

本版没有插件在线市场、自动下载安装更新、GitHub OAuth 登录、PR 管理、强推或内置冲突编辑器。
