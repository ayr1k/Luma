# Luma 使用说明

## 开始使用

在连接设置中填写模型主机地址和客户端密钥，刷新模型列表并选择模型。添加本地项目，或创建独立聊天。文件和工具在用户电脑上执行，模型在配置的服务上推理。

## 对话与模式

- Chat：日常问答，不读取或修改项目文件。
- Plan：分析和规划，以只读工具为主。
- Work：执行文件修改，终端命令需要审批。

模式与模型在输入区右侧选择。输入 / 搜索 Skills，输入 $ 选择工具插件。通过加号添加图片或文件，模型是否能理解图片取决于其能力。联网按钮启用基于 DDGS 的搜索。

对话支持流式输出、复制、编辑历史提问后重新生成和删除。删除会话不会删除项目文件。可在项目下创建多个任务，并使用搜索、状态筛选、置顶与归档管理。

## 文件与修改审阅

项目文件提供只读预览、语法高亮和行号。文件变更页面可以按轮次查看差异，选择保留或安全撤销。

保留不创建 Git 提交。撤销按文件的累计 Agent 修改恢复，不是只撤销当前筛选轮次；发现后续修改时会阻止覆盖。终端或插件产生的修改也应在 Git 中检查。

Git 的准备、暂存、提交、历史、分支、远程同步及认证，请从帮助菜单单独打开 **Git 和 GitHub 支持**。

## 上下文管理

上下文用量是估算值。在模型档案中设置上下文窗口，0 表示未知。可为早期对话生成摘要草案，检查、编辑并确认后生效。摘要可能遗漏内容，完整历史保留并可恢复。

历史分支复制对话，不复制或回滚项目文件。多个对话仍共享同一个项目目录。看到草稿已保存提示后，重启可恢复文字和附件引用。

## 扩展与设置

扩展中心支持工具插件、外观插件、软件功能插件及 Skills，可从 ZIP 或开发目录安装。项目可以设置默认扩展；每次发送前仍可移除选择标签。

参数设置用于模型的重要生成参数，软件设置用于外观、字体和交互。模型能力与诊断可检查工具、视觉等兼容性。扩展格式和开发方法见独立的扩展开发指南。

## 后台与退出

关闭窗口后 Luma 留在系统托盘。通过托盘菜单彻底退出。后台任务完成时可显示 Windows 通知，实际显示受系统通知设置影响。

## 更新与渠道

安装包中可选择 Latest 或 LTS。覆盖安装前从托盘彻底退出程序。渠道政策及路线图见帮助菜单的 LTS 说明与 Road map。重要项目应通过 Git 或其他备份方式保存。

## 0.8.0 SoHo 新功能

左侧“克隆仓库”可从地址建立本地项目。Git 页面“操作记录”便于排查同步失败。帮助菜单“检查更新”区分 Latest/LTS，可关闭启动自动检查，下载后手动选择安装渠道。

扩展详情提供来源、目录和版本回退；安装前检查替换版本与权限。扩展中心“检查预置更新”修复可自动升级的旧包；“升级兼容检查”展示设置备份位置与无法读取的文件。升级后重新启用插件，用户配置和数据保留。

中版本代号：0.8.x 为 SoHo，后续中版本各采用一个纽约地名。安装包仍按 Luma-Setup-版本号.exe 命名。
