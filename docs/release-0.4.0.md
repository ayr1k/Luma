# Local Agent 0.4.0 预览版

关闭旧版窗口与后台服务，运行 `LocalAgent-Setup-0.4.0-preview.exe` 覆盖升级。项目、会话与连接配置仍保留在 `%LOCALAPPDATA%\LocalAgent`。

## 主界面选择模型

- 主界面顶部新增模型按钮。点击展开列表，可搜索名称、选择模型、查看选中标记，或手动刷新。
- 启动时以及保存连接后，客户端自动向已配置的 LiteLLM 地址请求 `/v1/models`，使用当前客户端的 Virtual Key。显示的是该密钥可见的模型 ID，不是预置的演示名单，也不是扫描局域网里的其他设备。
- 连接设置只需主机 API 地址与密钥，不再填写模型名称。
- 保留原来的选中模型；若它已不可用，请在列表中选择其他模型后发送任务。没有可用模型、主机离线或密钥失效时会显示提示，可以刷新重试。
- 切换用于后续对话，保留当前会话历史与文件修改。任务执行中、等待命令审批时禁止切换。
- 默认记住模型选择；它按主机地址保存，不包含密钥。在连接设置取消“在这台电脑上保存”时，本次后续模型切换也只在当前进程生效。
- 读取列表不发起推理；“测试模型连接”仍可单独验证所选模型能否推理。列表可见不代表模型一定支持工具调用，模型能力由主机部署决定。

## API

- `GET /v1/models`：返回 models、selected、available。
- `PUT /v1/models/selection`：提交 `{ "model": "模型ID" }`。服务重新验证模型可见性，再保存选择。
- `PUT /v1/configuration` 的 model 字段改为可选，以兼容旧客户端。
- 新增接口沿用本机令牌认证和仅本机访问限制。密钥不会返回页面。

## 验证

- 回归测试：36 项通过，2 项因 Windows 沙箱符号链接/DPAPI 环境限制跳过。
- 使用模拟 OpenAI 兼容传输验证：模型列表去重、密钥认证、所选模型进入实际请求参数、跨重启保留选择、空列表、模型移除、密钥失效、运行中和审批中禁止切换。
- 真实本机 HTTP API 与 Edge 页面联调通过：获取列表、搜索、切换、刷新、审批、任务完成与停止。测试模型由确定性模拟服务提供；预览图中的三个名称是测试数据。
- 本轮未对真实局域网主机上的全部模型逐一推理；原生窗口与安装升级仍需在正常用户桌面验收。安装包未代码签名。
