# Luma 0.7.7：Git 本地版本管理

一个 Luma-Setup-0.7.7.exe，安装时选择 Latest 0.7.7 或原有 0.7.2 LTS。新增界面沿用现有主题、圆角、菜单及差异配色。

- 独立 Git 页面：环境检测、仓库初始化、仓库根目录、分支及身份状态。
- 未暂存/未跟踪/已暂存分组，单文件和批量暂存、取消暂存。支持逐行差异与前后对照。
- 本地提交只包含已暂存内容，确认前展示文件数量及提交说明。模型可按需生成说明，失败保留输入。
- 最近 40 次提交历史与文件差异、本地分支创建和切换；存在未提交修改时阻止切换。
- 未检测到 Git 时提供官网下载、重新检测和手动路径配置；未配置身份仍可查看及暂存，默认只配置当前仓库。
- 初始化可添加基础忽略规则，不覆盖已有 .gitignore；位于上级仓库中的项目会明确显示整个仓库范围。

Git 操作与 Agent 操作共用执行锁，并检查待审批任务、仓库状态、冲突和未完成合并。所有文件参数通过独立参数及字面路径传递，不接受任意 Git 命令。Git 提交、分支操作都需要用户明确发起。

不包含远程同步、GitHub 登录、冲突编辑器或分支删除。需要本机安装支持 switch / init -b 的 Git（建议 Git 2.28 及以上）。Luma 不捆绑 Git。大型差异只显示部分预览，超大仓库状态会提示使用外部工具。

生成提交说明会将暂存差异发送给当前配置的模型，最长使用约 24 KB；有截断时明确提示。模型不会自动提交。

现有文件审阅、会话格式及插件 API 保持兼容。LTS 程序未合入本次 Git 功能。关闭正在运行的 Luma（含托盘）后覆盖安装。
