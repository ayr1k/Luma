# Luma 0.7.3 Latest 与 0.7.2 LTS

- 每个主机/模型分别保存 Temperature、Top P、输出上限、思考强度和超时；首次使用继承迁移时的参数默认值，切换模型恢复对应设置。
- 新增模型能力与诊断页：人工能力标记、未知的主机声明、带时间的实际探针结果分别呈现。
- 独立测试连接/模型列表、文字、流式、工具调用和思考参数。测试只发固定内容，不执行模型返回工具；不会把失败直接判定为永久不支持。
- 诊断报告仅导出数值参数、能力标记、测试代码和时间，不包含密钥、地址、模型名、历史或原始错误。
- 模型请求失败提供认证、权限、连接、限流、参数拒绝和截断等分类提示，不自动重放工具。
- 0.7.2 成为首个 LTS；统一离线安装器选择真实 Latest 或 LTS 程序，默认/自定义预置扩展安装继续可用。
- 帮助菜单新增 LTS 说明与 Road map，两条渠道均离线可读。

退出托盘后覆盖安装。LTS 政策与切换兼容范围详见 lts.md。预置包不变，不因本次更新撤销既有信任。暂无在线更新服务。

修改模型生成参数后会清除该模型的旧探针结果，避免把旧参数下的通过状态当作当前结果。主机能力声明目前保持未知；图片支持可手工标记，本版不自动测试视觉理解。

验证：177 项自动测试通过，2 项 Windows 环境限制跳过。分项探针使用隔离 OpenAI 兼容模拟主机验证，未测试真实 LAN 模型能力。Latest/LTS 默认安装、自定义组件及双向切换的数据保留通过隔离安装规则测试；测试未覆盖用户现有安装。两份冻结程序核心自检通过；凭据存储自检仍报告既有环境错误 2。安装包未代码签名。
