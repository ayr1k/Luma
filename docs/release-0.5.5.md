# Luma 0.5.5

## 系统托盘与后台运行

点击窗口右上角关闭按钮，窗口隐藏，Luma 继续在右下角系统托盘运行。图标可能位于 Windows 折叠区域。双击图标或右键选择“打开 Luma”恢复窗口；右键选择“退出 Luma”彻底退出。

退出时停止后续模型步骤和工具调用，等待正在进行的请求或命令到达安全结束点，然后关闭本机服务。期间图标显示“正在安全退出”；网络请求无响应时可能需要等待超时。不会强制中断文件写入，也不会自动回滚已完成修改。

## 完成任务提示

窗口隐藏期间，任务完成、等待命令审批、任务失败会发出 Windows 系统托盘通知，点击通知可恢复窗口。通知由后台任务触发，不依赖前端轮询；前台窗口正常显示时不通知。通知只包含状态，不显示提问或文件内容。

通知通过 Windows NotifyIcon 系统通知接口发送。实际显示位置、样式和是否显示受系统通知设置、勿扰模式及 Windows 版本影响。

## 升级与验证

先从旧版本退出，再运行 Luma-Setup-0.5.5.exe 覆盖安装，保留项目、会话和设置。

79 项测试通过，2 项因 Windows 沙箱限制跳过。覆盖关闭隐藏、恢复、后台通知条件、安全退出等待及重复退出、后台完成回调。原生 Windows Forms 自检已创建托盘图标和右键菜单并验证隐藏与释放资源。

测试环境不能确认普通桌面通知弹出的实际效果及完整 WebView2 隐藏/恢复体验，需在普通 Windows 桌面验收。凭据加密自检仍有旧版相同的沙箱系统错误 2。安装包未代码签名。
