# Luma 0.7.6：菜单与会话界面修复

本次提供一个 `Luma-Setup-0.7.6.exe`，安装时选择 Latest 0.7.6 或保持原有功能的 0.7.2 LTS。

## 工具卡片对齐

移除文件路径上多余的顶部间距，统一文件名、操作名称和成功/失败状态的行高及垂直对齐。长路径仍会省略显示，鼠标停留可查看完整路径。

## 统一下拉菜单

以主页状态筛选为样式基准，把文件选择、变更审阅范围、对照方式、参数/软件设置、模型能力标记及动态生成的扩展设置选择器改为应用内菜单。模式、模型和状态筛选继续使用已有的应用内菜单。

新菜单使用当前主题的背景、文字、边框和强调色，统一圆角、选中标记和简短过渡动画；遵循减少动态效果的系统偏好。根据可用空间向上或向下展开，点击外部、按 Escape、滚动外部容器或调整窗口时收起。

支持方向键、Home/End、Enter 和 Escape。选项超过 8 项时显示搜索框；匹配超过 150 项时提示缩小搜索范围，不静默省略。选项列表和禁用状态由原有选择器驱动，保留已有设置值和操作行为。

## 删除会话后的界面清理

修复删除成功后仍访问已移除的旧差异容器，导致刷新中断、侧栏保留已删除会话并出现 Unknown project 的问题。

删除成功后立即移除对应列表记录；删除当前会话时清空聊天、草稿、附件、上下文和文件审阅状态，返回初始界面。最后一个会话删除后显示空列表。删除非当前会话不会清空当前对话或其草稿；取消或服务端删除失败时保留原界面。

删除对话仍不删除项目文件。若删除已成功但之后的列表刷新失败，已删除的条目不会重新留在侧栏。

## 验证与兼容

本版不修改会话存储格式或插件 API。新增 5 项前端删除生命周期回归检查，并运行原有 Python 测试。界面使用隔离数据验证，不操作用户的实际会话。

开发者可运行 `node --test tests/test_ui_lifecycle.cjs` 检查最后会话删除、非当前会话删除、取消、删除失败和刷新失败的处理。

LTS 程序未合入本次 Latest 界面改动。仍保留预置扩展的默认/自定义安装和项目 GPL-3.0 许可证文件。安装包未代码签名；正常 Windows 桌面的安装及凭据保存不由模拟界面测试覆盖。
