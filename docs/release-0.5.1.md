# Luma 0.5.1

关闭旧版窗口和后台服务，再运行 `Luma-Setup-0.5.1.exe` 覆盖升级。原有项目、会话、密钥和参数设置保留，数据目录不变。

## 删除对话

侧栏每条记录右侧新增删除按钮。点击后会显示应用内确认框，默认聚焦“取消”。确认后清除该对话的历史、工具记录、待审批命令和变更追踪，并从侧栏移除。

项目文件和已经完成的文件修改会保留，不会删除或回滚；删除后也无法再用该对话的变更追踪回滚。重新添加同一项目会开启空白会话，不恢复已删除的历史。任务运行中不能删除，请先停止或等待结束。删除等待审批的对话会丢弃审批，命令不会执行。

原有 `DELETE /v1/projects/{id}` 接口现在同时清除对话历史与列表记录；它不会递归删除项目目录或对话目录。

## 流式输出

模型请求改用 OpenAI 兼容的 `stream=true`，接收文本增量时即可显示。模型到客户端是真实流式传输；桌面通过约 150 毫秒一次的本机任务快照刷新文本，不再等待整段回复结束。向上阅读时不强制滚动到底部。

流式工具调用的名称和参数会先完整组装，在收到正常结束标记后才进入工具执行与审批。截断、网络错误或达到输出长度限制时，已经显示的文字保留，未完成的工具不会执行。不会因流式失败自动重发模型请求或命令。

点击停止会在收到下一段流数据时结束读取；如果主机暂时没有返回数据，可能需要等待下一段或请求超时。原有 Work 命令执行的停止边界保持不变。主机必须支持 OpenAI 兼容流式聊天接口。
