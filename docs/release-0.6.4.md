# Luma 0.6.4

任务过程与对话体验更新，保留 0.6.3 的项目、会话、扩展和配置。

- 真实进度：准备请求、等待模型、接收思考/回复、执行工具、等待审批、暂停和结束。不会用猜测的百分比代替真实事件。
- 工具卡片：在对话内显示工具名称、目标、成功/失败/拒绝/未执行，展开查看参数、结果及执行耗时。已有旧会话缺少定位信息的记录仍可在「工具记录」查看。
- 本轮操作摘要：汇总成功写入的文件、命令结果、插件调用。插件直接修改不纳入自动变更追踪；命令退出成功不代表所有测试通过。
- 生成控制：增加重新生成入口与明确说明。停止保留已完成修改；继续用于暂停任务；重新生成替换后续对话，但不回滚文件，工具审计保留并重新请求必要审批。
- 对话管理：右侧 ⋯ 菜单支持重命名、置顶、归档、恢复和删除。搜索支持名称及消息正文；活动与归档列表分开。待审批对话不能归档。
- 桌面体验：悬浮窗保存位置、恢复时避免落到不可见屏幕；快捷键从 3 个组合增至 18 个；点击完成通知会打开对应对话。

插件数量限制：

| 项目 | 0.6.3 | 0.6.4 |
|---|---:|---:|
| 已安装插件 | 30 | 100 |
| 同时启用代码插件 | 8 | 20 |
| 每轮选择工具插件 | 8 | 12 |
| 每轮选择 Skill | 8 | 8 |

新上限不会自动启用插件，也不会向模型自动加载全部插件。原有逐次审批、包摘要检查和工作模式权限继续保留。

从系统托盘退出旧版后覆盖安装。默认安装仍含 11 个预置插件和 5 个 Skill；自定义可逐项选择。未变化的插件保留原启用状态与配置，新包默认禁用。归档只修改列表状态，不移动项目文件。旧对话兼容；重新生成之前的工具记录保留在审计视图，不会混入新回复的工具卡片。


验证：153 项自动测试通过，2 项环境限制跳过。新增测试覆盖真实数量上限（100/20/12）、对话正文搜索、归档/恢复、待审批禁止归档、工具状态与时间持久化、多次重生成保留审计、异步准备状态、通知目标和快捷键配置、屏幕位置限位。

界面演示通过重命名、置顶、归档恢复、正文命中摘要；任务请求→审批→执行→完成；重生成重新审批；停止后未执行工具，以及停止后新任务正常运行。使用确定性演示模型，未调用真实 LAN 主机。

Windows 原生组件测试通过新组合 Ctrl+Shift+F9 注册、重复注册冲突、释放后重新注册，以及悬浮窗状态更新、位置保存恢复和关闭清理。默认 Ctrl+Alt+L 在本次环境已被占用，程序正确报告；没有抢占已有快捷键。通知目标传递和消费通过测试，普通 Windows 桌面的真实通知点击未完整人工验证。

隔离安装测试通过默认 11 插件 + 5 Skill、自定义跨分类选择、无扩展，以及重复安装保留未变化插件启用状态和用户 Skill。测试使用相同组件与文件规则，去除正式注册/快捷方式并使用独立目录，未覆盖安装用户当前程序。最终安装包与构建程序、界面、11 个预置包逐文件一致。

冻结程序自检通过 API、扩展工具子进程、附件及搜索依赖。凭据加密自检仍有此前环境错误 2；两项测试因 Windows 环境权限跳过。本版未修改凭据机制，安装包未代码签名。
