# Luma 0.6.3

- `/ Skills` 与 `$ 插件` 独立选择。工具插件只向本轮明确选择的插件开放；Work 模式与逐次审批保持不变。
- 输入区左侧放置 Skills、插件、附件、联网与可选快捷短语；右侧依次是模式、模型、发送。长模型名省略，窄窗口整组换行。
- 新增四个外观插件：配色工作室（四套配色与强调色）、阅读排版（本机字体、字号、行距、宽度）、轻盈图标（细线/圆角）、半透明面板（应用内材质）。可组合，同类互斥，支持恢复原软件外观设置。
- 新增三个软件功能插件：桌面悬浮组件（拖动、置顶、任务状态、打开主窗口）、全局唤起（可选快捷键与占用检测）、快捷短语（编辑、分类、搜索、插入，不自动发送）。
- 外观/软件插件提供受控声明式配置，开发者可导入 ZIP/开发目录；不支持注入任意脚本。范围和示例见扩展开发指南。

从托盘退出旧版，再覆盖安装。默认安装包含全部 11 个插件及 5 个 Skill；自定义安装可逐项选择。新插件全部默认禁用，旧外观、项目、会话、配置保留。悬浮窗和快捷键需要在扩展中心主动启用。未变化的旧插件保持启用状态；更新包会禁用并撤销代码信任。

悬浮窗共用主窗口任务与审批，点击打开返回主窗口，关闭按钮也返回主窗口；在扩展中心禁用可收起组件。透明插件只提供应用内部效果，不改变 Windows 窗口本身透明度。字体需已在本机安装。

便携版附带全部预置插件；独立 Skill 位于 Preset-Skills，可复制到扩展中心打开的 Skill 文件夹。自定义安装取消组件不会移除已有安装，可在扩展中心卸载。


验证结果：142 项测试通过，2 项受环境限制跳过。覆盖未选择插件禁止调用、所选插件范围、重生成与禁用校验、声明式配置拒绝越界值和代码、同类互斥、更新保留配置及已有功能回归。

浏览器演示验证了本轮插件选择 → 模型调用 → 审批 → 完成；快捷短语编辑保存与插入；深浅配色、字体与图标组合、恢复默认外观；850 × 600 窗口内模式/模型/发送间距，未见页面错误。Windows 原生组件测试通过快捷键注册、冲突、释放后重注册，以及悬浮窗创建、状态更新、禁用和资源清理。未在普通 Windows 桌面完整人工操作快捷键和悬浮窗拖动。

隔离安装测试通过默认 11 插件 + 5 Skill、自定义跨分类选择、无扩展，以及重复安装保留未变化插件状态和用户 Skill。测试使用同一组件/文件规则，去除正式注册和快捷方式、替换测试环境无法解析的默认路径，未覆盖用户当前安装。最终安装包的程序、界面和全部预置包与构建内容逐文件匹配。

冻结程序 API、工具子进程、附件与搜索依赖自检通过；未连接真实 LAN 模型进行推理测试。凭据加密自检仍有此前环境错误 2，2 项测试跳过与 Windows 环境权限有关；本次不修改原凭据保存机制。安装包未代码签名。
