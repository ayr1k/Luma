# Luma 0.6.5

本版完善插件与 Skills 的日常使用体验，继续支持本地 ZIP 和开发目录分发。

- 插件详情：作者、版本、兼容范围、能力、使用示例、更新说明；旧包缺失字段会显示“作者未提供”。
- 项目默认扩展：扩展中心或对话管理菜单配置。保存会应用到当前输入；空会话和从当前项目创建的新对话自动带入可移除标签。不可用默认项会跳过并提示，不自动启用或授予信任。新对话仍使用独立聊天目录，未改变一个项目一条主会话的架构。
- 输入区快捷搜索：/ 搜索 Skill，$ 搜索工具插件；支持光标位置、中文输入、上下键、Enter、Tab、Esc。原工具运行模式和审批要求不变。
- 配置迁移：JSON 文件导入/导出、预览差异值、一次性校验后保存。迁移已安装外观和软件功能插件的声明式配置，包括主题、字体和快捷短语；未安装项跳过，版本不同按当前配置规则验证。不包含代码、密钥、项目历史、启用或信任状态。快捷短语内容会包含在导出文件中。
- 扩展诊断：插件/Skill 未启用、包内容变化、版本不兼容、配置无效，以及本机悬浮窗/快捷键状态。
- 开发者检查：在扩展中心检查 ZIP 或目录，或使用 `python -m local_agent check-extension 路径`。报告 JSON 行列、工具 schema 字段路径、Python 语法位置、缺失入口/Skill 文件。只做静态检查，不执行代码，不代表运行时行为已验证。

数量限制维持 0.6.4：100 个安装插件、20 个启用代码插件、每轮 12 个工具插件和 8 个 Skill。

升级前从系统托盘退出旧版，再覆盖安装。会话、项目及配置保留。预置包新增详情信息，包内容更新会按现有机制禁用并撤销旧信任，请在扩展中心重新启用需要的预置插件；已有声明式配置会保留。

安装包未代码签名。真实局域网模型及普通桌面的原生保存对话框需要实际使用确认。

验证：158 项自动测试通过，2 项因 Windows 环境限制跳过。界面实测通过默认 Skill 保存与新对话继承、键盘搜索选择、详情、诊断、配置预览和导入后保留；无浏览器脚本错误。开发检查 CLI 通过。冻结程序自检通过 API、插件工具子进程、附件、搜索依赖和预置工具。凭据加密自检仍报告此前环境错误 2，本版未修改凭据机制。使用隔离演示数据，未修改用户项目或覆盖安装当前程序。
