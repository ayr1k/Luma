# Luma 0.5.7

修复 0.5.6 中工具已经成功执行、模型给出结束答复后，程序仍反复追加“继续当前任务”的问题。

Work 模式本轮有工具操作，且最后一次工具结果成功时，模型返回非空正文且没有新工具调用，就结束本轮，不再强制要求 finish。模型仍返回工具调用时继续正常执行；明确询问信息时仍暂停等待。

只计算本轮用户输入之后的工具记录，不把旧任务的成功当成本轮依据。最后一次工具报错、拒绝或取消不作为成功；终端命令要求退出码 0。尚未执行工具的规划仍保留默认 6 次无工具容限与可恢复暂停。显式 finish 保持可用。

结束本轮并不自动证明全部需求都已验证，具体操作和测试结果仍以工具记录、文件变更和模型说明为准。

升级前从系统托盘右键退出旧版，再运行 Luma-Setup-0.5.7.exe 覆盖安装。已有文件和对话保留；不会自动恢复或重跑之前停止的任务。建议用新对话验证修复，避免旧上下文中的重复催促影响回答。

92 项测试通过，2 项受 Windows 沙箱限制跳过。新增回归覆盖真实临时文件写入后自然结束、不多请求模型、旧工具成功不污染新一轮、工具错误不算成功、询问等待及多工具与 finish 兼容。冻结自检和安装包内容校验完成；未使用真实 LAN 模型重复执行你的项目任务。凭据加密自检仍有旧版相同的沙箱系统错误 2，安装包未代码签名。
