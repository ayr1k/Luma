# Luma 0.7.8：远程 Git 同步与帮助阅读器

提供唯一安装包 Luma-Setup-0.7.8.exe，安装时选择 Latest 0.7.8 或保持原功能的 0.7.2 LTS。

## Git 远程同步

- 添加、编辑和移除本地远程配置，展示获取/推送地址；可打开对应 GitHub 页面。
- Fetch 获取远程信息；Pull 只允许工作区干净时快进更新；Push 前确认目标及分支，只推送已提交历史，不强制覆盖。
- 展示跟踪分支及领先/落后数量，明确其为本地缓存，Fetch 后更新。
- 测试远程读取权限，提供认证、主机验证、网络和历史分叉的错误指引；复用本机 Git 凭据，不存储 GitHub 密码或令牌。
- 不自动登录、不自动接受 SSH 主机密钥，不自动合并/变基；冲突仍在外部工具处理。

## 帮助文档

修复帮助阅读器把 Markdown 标题等标记直接显示为正文的问题。标题、列表、代码块、表格、引用、强调及安全网页链接均按文档样式显示，并跟随主题。

重新整理说明书；帮助菜单新增独立的“Git 和 GitHub 支持”，涵盖环境、身份、暂存/提交、分支、远程配置、认证、Fetch/Pull/Push 与故障排查。说明书、更新日志、扩展开发指南和 LTS 文档共同使用新阅读器。

## 边界与升级

首次 HTTPS/SSH 认证在系统 Git 中完成后，返回 Luma 重试。GitHub Desktop 与系统 Git 的凭据不一定共享。远程操作最长等待约 120 秒，超时后应先 Fetch/刷新核对服务器状态。

本版不包含仓库克隆、PR 管理、强制推送、远程分支删除或内置冲突编辑器。现有会话与插件 API 保持兼容，LTS 程序未合入本次功能。

从托盘彻底退出 Luma 后覆盖安装。
