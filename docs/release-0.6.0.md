# Luma 0.6.0

本版加入插件与 Skills 支持，保留现有项目、对话、模型配置和审批流程。

## 新功能

- 侧栏「扩展中心」：导入本地 ZIP 或开发目录，查看名称、版本、说明、错误，启用、禁用和卸载插件。导入目录会复制到应用数据目录。
- 独立 Skill 文件夹：可在软件内新建、编辑、启用、禁用、删除，或打开文件夹编辑后重新扫描。插件自带 Skill 为只读。
- 显式调用：输入框输入 `/` 或点击 `/ Skills`，选择最多 8 项，发送前可移除标签。仅所选正文载入，资料按需读取。历史提问保留 Skill 快照。
- Python 工具插件：独立进程运行，参数验证、每次审批、30 秒超时、取消和进程清理。Chat/Plan 不允许执行代码插件。
- 安装路径与版本检查、摘要校验、失败回滚。安装及更新后默认禁用；更新撤销旧信任。
- 随附两个可安装 ZIP 示例：写作助手（纯 Skill）、项目概览（工具 + Skill），以及源码和开发指南。

## 开始使用

1. 从系统托盘右键退出旧版 Luma，再覆盖安装 0.6.0。
2. 打开侧栏「扩展中心」，导入示例 ZIP，启用插件。
3. 进入 Skills 页查看可用技能，或创建自己的 Skill。
4. 回到对话，点击 `/ Skills` 选择，再发送消息。
5. 项目概览工具需在 Work 模式使用；模型请求后会出现「批准插件工具」。

默认用户 Skill 路径：`%LOCALAPPDATA%\LocalAgent\skills`。每项使用 `<id>/SKILL.md`，UTF-8 文本。设置 AGENT_DATA_DIR 时以实际数据目录为准。

## 边界

代码插件是受信任本地代码，具有当前用户的文件与网络权限；独立进程不等于操作系统沙箱。仅启用可信作者代码。插件直接修改的文件不自动纳入 Luma 变更撤销。Luma 不主动把模型密钥传给插件，但可信代码仍可能读取用户有权限访问的文件。

本版承诺 Python 标准库插件，不自动安装额外依赖。暂无插件市场、在线自动更新和任意 UI 插件。卸载保留数据与回收副本。Skill 文本会随请求发送到当前模型主机；引用资料读取当前版本。实际模型需支持工具调用。

## 验证

112 项测试通过，2 项受 Windows 环境限制跳过。新增测试覆盖路径越界、重复路径、链接、版本与参数校验、信任撤销、更新失败回滚、Skill 选择与历史快照、模式限制、审批不可重放、拒绝执行、进程超时与取消。

隔离界面测试完成：导入预览、默认禁用、信任启用、Skill 编辑/只读查看与选择、插件审批、结果返回、深浅色显示。冻结程序自检通过，包括无需外部 Python 的插件进程运行。Windows 凭据加密自检仍出现既有环境错误 2；2 个跳过项涉及 Windows 链接及凭据加密环境限制。

端到端验证使用确定性演示模型，未向实际 LAN 主机发送测试任务。安装程序未代码签名。
