# Luma LTS 说明与 Road map

LTS（Long-Term Support，长期支持版）用于保持插件生态和接口兼容性，为长期使用者提供变化较少、风险可控的稳定版本。Latest 用于持续功能迭代；LTS 优先处理重要缺陷、安全问题和既有扩展兼容问题，不主动引入新功能或破坏性接口变化。LTS 不代表没有缺陷，也不等于所有第三方插件都已通过验证。

## 选定与转入规则
1. 大版本按首位划分：0.x.x、1.x.x、2.x.x，各选一个 LTS 锚点。0.8.0 仍属于 0.x.x，不自动新增 LTS。
2. 在每个大版本中选择较稳定、功能基本完善的版本作为候选锚点。
3. 候选版本之后的下一次版本迭代发布时，该锚点正式转入 LTS。
4. 当前 LTS 的支持和下载窗口保留至下一代 LTS 正式发布。下一代尚未确定时，当前窗口持续开放；不预设或承诺未经确定的日期。
5. LTS 维护更新保留锚点名称并增加维护修订号（例如 0.7.2 LTS r1），公布修复内容和兼容性变化。只回移经过验证的必要修复；重大功能继续进入 Latest。

## 路线图
- 0.x.x：锚点为 0.7.2 LTS，在 0.7.3 发布时转入；支持与下载保留至 1.x.x 的 LTS 正式发布。
- 1.x.x：在该系列中选定稳定版本，下一次迭代后转入 LTS；支持与下载保留至 2.x.x 的 LTS 正式发布。
- 2.x.x 及以后：每个大版本选一个锚点，沿用相同转入和支持窗口规则。

## 安装与渠道切换
统一离线安装器可选择 Latest 0.8.0 SoHo 或 LTS 0.7.2，安装实际对应的程序。预置扩展仍可默认安装或自定义选择。0.7.2 LTS 保留 0.7.2 的功能，只补充渠道标识和本说明。

切换前从托盘彻底退出 Luma。当前两条渠道使用同一安装位置和用户数据目录，可覆盖切换，不应同时运行。切换渠道前建议备份用户数据目录（默认 %LOCALAPPDATA%\LocalAgent）及重要项目文件。

0.7.3 模型档案保存在新增 model-profiles.json，旧有 preferences.json 字段不变；LTS 忽略模型档案，使用原有全局参数。返回 Latest 后仍使用各模型已保存的档案。此兼容结论仅针对当前 0.7.2/0.7.3，不承诺未来任意跨版本降级。

## 插件与下载维护
插件作者应分别声明最低/最高支持范围与实际测试版本，以 LTS 作为稳定适配基线；主程序处于 LTS 不会绕过插件范围检查、信任或审批。预置包本次不改动，兼容范围仍为 0.7.x。

当前通过 GitHub Releases 分发单一统一安装包，命名为 Luma-Setup-最新版版本号.exe。仓库若为私有，下载需要仓库访问权限。软件尚未提供自动更新服务。0.7.4 新增的摘要和草稿不会改变 LTS 行为，切换说明见 release-0.7.4.md。

0.7.5 的轮次审阅保存在 agent_changes 附加字段中。LTS 继续采用累计保留与回滚；跨渠道处理后对应追踪可能已清除。切换前备份项目和数据。

0.8.0 起统一安装器按所选渠道安装各自的预置包。Latest 提供公开发布信息检查，不自动安装更新。0.8.x 代号 SoHo 不改变 LTS 划分。
