# Luma 0.7.4：对话与上下文管理

本次仅提供统一安装包 `Luma-Setup-0.7.4.exe`，可选择 Latest 0.7.4 或保持不变的 0.7.2 LTS。

## 上下文用量

输入区上方显示已保存历史的 Token 估算。“上下文管理”中按当前主机和模型设置参考窗口，0 表示未知。百分比包含输出预留，不含未发送草稿。按字符估算，图片暂按每张约 1024 Token 计入，工具定义也计入；不是模型实际用量或计费统计，不保证与主机分词器一致。首次请求前的提示词、模式和扩展变化也可能造成偏差。不会根据估算自动删除历史或拒绝发送。

## 长对话摘要

至少三轮带索引的历史可以生成摘要，最近两轮保留原文。“生成摘要草案”将早期对话和已有摘要发送给当前模型，独立请求不提供项目或终端工具。可取消，失败保持原上下文。待摘要内容超过 12 万字符时明确拒绝请求，不静默截断。

草案可以编辑，确认后才用于后续请求；完整聊天与工具历史始终保留。“恢复完整上下文”可以撤销摘要。摘要可能遗漏信息，图片仅保留存在提示，不会进行视觉理解。摘要不比原文更短时拒绝应用。缺少轮次索引的旧会话暂不支持摘要，可新建对话。

## 历史分支

“修改”和“重新生成”创建新分支，原对话不被覆盖。“分支对话”复制当前完整历史而不立即生成；分支显示来源并可返回原对话。

分支共用项目文件夹，不是文件快照。文件不会回到历史状态，重新生成仍可能产生新操作。工具历史仅供参考，不会重放；运行、暂停、中断或待审批状态需先处理。撤销记录属于原会话，不复制到分支。原对话删除后，分支仍可独立使用。

## 草稿恢复

每个对话的文字、附件、选中 Skills 和工具插件保存在本机 drafts 目录。显示“草稿已保存到本机”后，重启并打开该对话可以恢复。约每 0.7 秒检查保存，切换对话时先保存；尚未出现已保存提示就异常退出，最后输入可能尚未落盘。最多 4 个附件，合计约 20 MB。附件草稿保存在本机，发送时才进入模型请求。失效扩展会跳过并提示。

发送被接受后清除草稿，请求校验失败时保留。删除或清空对话会清除对应草稿。

## LTS 与构建

新增字段与独立草稿文件保留旧会话格式。0.7.2 LTS 忽略摘要并使用完整历史，不提供草稿恢复或分支入口。回到 Latest 时检查摘要对应的历史；若在 LTS 中修改过历史，旧摘要失效。LTS 编辑仍采用旧行为，切换前请备份数据。

scripts/build-release.ps1 指定 LTS 源码目录，只生成一个可选渠道安装包；官方 LTS 基线为 v0.7.2-lts。暂无软件自动更新功能。

## 验证范围

自动测试覆盖摘要边界、历史保留、取消、无工具执行、LTS 失效保护、分支隔离、草稿恢复与鉴权。界面使用隔离模拟模型验证，不代表真实 LAN 模型的摘要质量。冻结程序和安装包通过隔离环境检查，未覆盖用户当前桌面安装。安装包未代码签名。
