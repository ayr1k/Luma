# Luma 0.5.2

关闭旧版窗口和后台服务，运行 Luma-Setup-0.5.2.exe 覆盖升级。项目、会话、密钥、参数和软件设置保留，原有数据目录不变。

## 浅色模式

修复主题变量作用范围，聊天背景、侧栏、输入框、按钮文字和消息统一切换；调整浅色下链接、提示和错误文字的对比度。

## 图片与文件

点击输入框左下角“+”选择附件，可预览图片、移除附件，再与文字一起发送，也支持只发送附件、粘贴图片。历史消息保留附件名称和图片缩略图。

- 图片：PNG、JPEG、WebP；发送为视觉消息，请选择支持图片的模型，主机网关也需要支持。图片最多 2000 万像素，发送前自动缩放至最长边 2048 像素并转换为 JPEG。
- 文件：TXT、Markdown、CSV、JSON、常见代码文件，以及 PDF、DOCX。文件在本机提取文字后发送；PDF/DOCX 的图片、版式不传递。扫描 PDF 暂不支持，请将页面作为图片发送。
- 每条消息最多 4 个附件；单个不超过 10 MB，合计不超过 20 MB；提取文字合计最多 60000 字符，PDF 最多 50 页。
- 附件内容会发往当前连接的模型主机。损坏、加密、过大或不支持的文件会被拦截；发送验证失败时草稿附件保留。
- 模型列表不保证报告视觉能力，无法自动替用户判断。模型拒绝图片时会显示提示，不会悄悄丢弃图片重试。

61 项测试通过，2 项受 Windows 沙箱限制跳过。覆盖附件类型与大小校验、图像规范化、PDF/DOCX 文本提取、历史保存、同步与异步接口，以及原有审批、删除和流式功能。

实际页面已验证浅色显示、图片与文本文件选取、发送和历史预览；本机模拟模型确认收到多模态内容。未对真实 LAN 主机逐模型验证视觉理解能力。冻结程序验证本机 API、UI、图片/PDF 依赖及搜索模块；安装包内容经过校验。安装包未代码签名。

当前测试环境的 Windows 凭据加密自检返回系统错误 2，与旧版相同；普通 Windows 桌面的凭据保存和覆盖安装需实际环境验收。此次未改动凭据加密逻辑。
