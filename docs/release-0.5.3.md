# Luma 0.5.3

关闭旧版窗口及后台服务，运行安装包覆盖升级。原有项目、会话和配置保留。

## 消息操作

- 新消息显示本地发送时间，悬停可查看完整日期。旧消息没有记录时间时不伪造时间。
- 模型文本回复显示生成耗时，从请求开始到流式回复结束，包括等待首段输出的时间，不包括人工审批等待。
- 提问和回复下方可点击“复制”，复制原始文本（包括 Markdown）。
- 点击历史提问下方“修改”，编辑后选择“保存并重新生成”。此提问之后的对话被替换，原有附件保留。使用当前选择的模型和模式。
- 已执行的文件修改不会回滚，工具记录和变更追踪保留。待审批、正在运行和中断任务不能直接编辑重跑；终端命令仍需重新审批。
- 暂不提供历史分支切换；编辑后替换的后续消息不能从界面恢复。

## 验证

65 项测试通过，2 项因 Windows 沙箱限制跳过；覆盖编辑截断上下文、附件保留、无效请求无修改、时间字段及既有功能。实际页面验证时间显示、复制和编辑重生成。未对真实 LAN 模型执行本轮推理测试。

安装包未代码签名。冻结程序的 Windows 凭据自检在本测试沙箱中仍返回系统错误 2，与旧版相同；普通桌面的凭据保存及覆盖升级需实际环境验收。
