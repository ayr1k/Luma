# Luma 0.7.5：文件变更审阅

统一安装包 `Luma-Setup-0.7.5.exe` 可选择 Latest 0.7.5 或 0.7.2 LTS。LTS 的功能与程序保持不变。

## 审阅工作流

“文件变更”改为文件清单与对照面板。左侧按文件选择，右侧可切换带行号和增删颜色的逐行差异、修改前后原文对照。支持浅色/深色主题和较窄窗口。

“全部待审阅修改”比较首次未处理的 Agent 文件编辑前快照与当前磁盘内容。轮次筛选比较该轮第一次编辑前与最后一次编辑后的历史快照，并标出本轮；同一文件同轮多次修改合并展示。旧版会话仍可审阅累计修改，但不能追溯升级前未保存的逐轮快照。

没有使用内置 write_file/apply_patch 的回复不会凭空产生文件记录。终端、插件和手工修改不归属于 Agent 文件工具快照，可通过独立 Git 变更入口辅助查看。Git 状态包含暂存和未跟踪条目，文本 diff 目前仅包含未暂存差异；它不是完整的 Git 客户端。

## 保留与撤销

勾选一个或多个文件后，选择“保留所选”或“撤销所选”。保留清除所选文件的累计追踪与轮次快照，不修改磁盘文件、不创建 Git 提交。撤销恢复原始字节；Agent 新建的文件会被删除。未选择的文件及记录保留。

**即使按轮次筛选，保留与撤销仍作用于所选文件的全部待审阅累计修改，不是只撤销某一轮或某几行。** 操作确认会重复说明此范围。本版不提供逐 hunk 撤销。

操作前重新核对审阅版本与文件哈希。文件被其他会话、插件或手工再次修改时禁止撤销，审阅后变化则要求刷新。路径越界、目录替换或损坏快照也会阻止撤销。批量操作按文件处理，部分失败会保留失败项并说明原因，不宣称跨文件事务。

运行、暂停、中断、待审批或仍有工具队列时不可处理变更；同项目其他会话的待审批保护保持有效。先停止或处理任务，再审阅。

## 限制与兼容

- 非 UTF-8、二进制或超过 500 KB 的文件不显示文本对照；超过 12000 行的比较仅提供前后原文。没有静默截断后假称完整差异。
- 对照中的 +/− 数量是文本行差异，不是字节数。只改变换行时会单独提示。
- 轮次快照保存在原有 agent_changes 的附加字段中，不进入模型消息；它们会增加本地会话大小，保留/撤销后释放对应文件的快照。
- LTS 忽略新审阅入口，继续采用旧版累计追踪操作。分支仍共享项目文件，不继承原会话的回滚所有权。
- 文件哈希检查避免通常的后续修改覆盖，不构成对恶意本机进程并发替换的操作系统级隔离。
- 安装包增加仓库 GPL-3.0 LICENSE 和现有图标许可文件。Latest 与 LTS 的对应源码应与发布附件一同提供。

## API

- `GET /v1/projects/{id}/review`：文件摘要、审阅版本令牌及可用轮次。
- `GET /v1/projects/{id}/review/file?path=...&turn=...`：当前或指定轮次对照。
- `POST /v1/projects/{id}/review`：`action` 为 keep/revert，files 包含 path 和刚取得的 revision。

新接口沿用本机鉴权和任务互斥。旧批量回滚接口仍保留，并使用相同的安全撤销检查。

## 验证

自动化测试涵盖逐轮快照、多次编辑、逐文件保留/撤销、原始换行恢复、审阅过期、后续修改保护、目录替换、旧记录、大文件/二进制降级、分支、鉴权及批量部分失败。界面通过隔离模拟项目验证，不代表真实模型质量或当前用户桌面安装测试。
