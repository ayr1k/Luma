# Luma 0.6.2

## 四个预置工具插件

- 图片处理：检查格式、尺寸和帧数；等比缩小，另存 JPG/PNG/WebP；不覆盖原文件或已有输出，透明图片转 JPG 时使用白底。输出不复制 EXIF/GPS。暂不处理动画与多帧转换，不提供生成式修图。
- 项目概览：扫描目录树、文件类型和常见配置入口。跳过链接、依赖、缓存和构建目录；最多扫描 5000 项，目录展示最多 300 项，可指定深度，报告截断。
- 文档读取：按 PDF 页、DOCX 段落或 UTF-8 文本行读取；支持本次范围内的关键词筛选。PDF 每次最多 10 页，输出最多 20000 字符。只读取 PDF 文本层，不含 OCR；不读取加密 PDF，DOCX 图片与复杂版式不会还原。
- 文件整理：扫描重复内容但不删除。根据明确的源/目标映射生成计划，返回完整清单；执行时再次审批并检查文件摘要、冲突与项目范围。不会覆盖目标。执行记录保存在插件数据目录；部分失败可能保留两份文件，需检查记录，旧计划不能重放，暂无自动撤销。

所有内置路径限定在当前项目内；处理其他目录时应把对应目录作为项目打开。代码插件依旧仅在 Work 模式执行，每次调用需审批；纯文本 Skill 可在三种模式选用。内置工具的路径检查并不意味着任意第三方 Python 插件有操作系统沙箱。

## 扩展中心

左侧是一级分类：工具插件、Skills、外观插件、软件功能插件。右侧按分类显示标题、说明、独立操作栏和内容列表。插件卡片标明「预置 / 本地导入」，可展开查看工具及操作范围。分类支持键盘方向键导航。

外观与软件功能插件仅预留入口，当前版本不开放安装或运行；明确声明这些类别的包会被拒绝，避免误以为已有完整支持。

## 安装和升级

默认安装包含四个插件及既有五个 Skill；自定义安装可逐项选择，也可全部取消。预置插件位于程序目录 Bundled-Plugins，首次启动自动导入用户数据目录，默认禁用；用户需在扩展中心确认信任后启用。配套 Skill 随插件启用后可在 `/ Skills` 中选择。

插件新版本导入会撤销旧信任，保留插件数据。启动扫描不覆盖本地导入的同名插件，不自动恢复用户已卸载的插件；需要恢复时导入提供的插件 ZIP。取消安装组件不会删除此前已经安装的插件，可在扩展中心卸载。

便携版附带全部 Bundled-Plugins，首次运行按上述规则导入；Preset-Skills 文件夹中的独立 Skill 仍需按需复制到扩展中心打开的 Skill 目录。

从系统托盘退出旧版后再覆盖安装。原项目、会话、连接配置及用户 Skill 保留。插件直接修改文件不纳入 Luma 自动撤销。


## 验证结果

129 项测试通过，2 项受 Windows 环境限制跳过。新增覆盖四个预置工具、PDF/DOCX 分段、图片输出与原件保留、工作区越界、文件摘要变化和目标冲突、完整整理清单、旧计划不可重放、文件时间戳保留，以及预置插件更新/卸载/本地替换。

隔离安装测试验证了默认四插件五 Skill、自定义两插件一 Skill、完全不装扩展，以及重复安装保留已启用的未变化插件和用户 Skill 修改。组件测试采用相同选择定义与文件规则，去除了正式软件的快捷方式、注册信息和启动操作，并替换测试环境无法解析的 localappdata 默认路径；未覆盖安装到当前用户的正式程序。

最终冻结程序启动时自动导入四个预置插件并保持禁用；四类工具的独立进程自检通过。安装包主程序及插件文件与构建源码校验一致。界面完成深浅色、分类层级、预留入口、信任启用及模型审批后执行的演示验证。

端到端模型使用确定性演示，未向真实 LAN 主机发送测试任务。凭据加密自检仍出现已有环境错误 2；安装程序未代码签名。
