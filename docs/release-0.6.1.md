# Luma 0.6.1

- 扩展中心按钮加入与同菜单一致的线性图标，统一尺寸、间距、文字起点和深浅色表现。
- 安装程序提供「默认安装」与「自定义安装」。默认选择全部五个预置 Skill，自定义可逐项选择或全部不装。
- 预置内容：写作与润色、代码审查、故障排查、需求拆解与实施计划、文档总结与行动项。均为纯文本工作说明，不运行插件代码，不改变 Chat/Plan/Work 权限。

安装后从输入区 `/ Skills` 选择使用；不会自动应用。可在扩展中心编辑、禁用或删除。预置文件放在实际用户数据目录的 skills 子目录；默认 `%LOCALAPPDATA%\LocalAgent\skills`，设置 AGENT_DATA_DIR 时使用该目录。

安装和升级不覆盖已存在的同名 SKILL.md；取消某个安装组件不会删除以前安装的 Skill。卸载程序也保留用户 Skill。若曾删除预置 Skill，再次选择安装该项会补回。

升级前请从系统托盘退出旧版 Luma，再覆盖安装。项目、会话与配置继续保留。便携版附带 Preset-Skills 文件夹，按需复制其中的子文件夹到扩展中心打开的 Skill 目录。


验证：112 项自动化测试通过，2 项受 Windows 环境限制跳过。五个预置 Skill 的实际发现、编辑属性与选择验证通过；界面实测四个菜单按钮均为 39px 高、13px 字号、19px 图标、10px 图文间距。

使用相同组件定义、文件规则和 Skill 路径解析函数的隔离安装测试通过：默认安装五项、自定义两项、不安装 Skill、升级保留修改、取消选择保留已有文件。测试安装器移除了正式软件的快捷方式、注册信息和启动操作，并使用测试目录；正式安装器未覆盖安装到当前桌面。当前测试环境无法解析 Windows localappdata shell 常量，隔离测试指定了数据路径。

最终安装包内主程序与构建产物一致，五个 Skill 内容与源码一致；冻结程序自检通过。凭据加密自检仍存在此前的环境错误 2，安装程序未代码签名。
