# Luma 0.5.0

Local Agent 正式更名为 **Luma**。关闭旧版窗口及后台服务，再运行 `Luma-Setup-0.5.0.exe` 覆盖升级。

为兼容既有安装，安装标识和旧安装目录保持不变；用户数据仍在 `%LOCALAPPDATA%\LocalAgent`。原有项目、会话、修改追踪、连接密钥和模型选择继续使用，不必搬迁。新版入口为 Luma，安装器清理旧程序入口与快捷方式，不删除用户项目和数据。安装包尚未代码签名。

## 新界面与图标

参考提供的深色桌面界面重做：窄导航栏、可折叠项目侧栏、居中对话、底部输入框；模型选择移入输入框工具栏。支持项目搜索、新对话、Markdown 标题/列表/代码/来源链接和浅色外观。图标采用 Phosphor 的 Sparkle 与同系列线性图标，许可证随源码提供。

## 三种模式

| 模式 | 可用能力 |
|---|---|
| Chat | 普通对话，不读取项目文件、不修改文件、不执行命令 |
| Plan | 阅读和搜索项目、查看 Git diff、制定计划；禁止写入和终端执行 |
| Work | 本地文件读写、补丁、搜索、Git diff；终端命令仍必须审批 |

开启联网后，三个模式都可调用搜索。权限限制同时落实在模型工具列表和 Core 执行层，即使模型返回不允许的工具调用也会被拒绝。模式变更用于后续任务，已有会话历史仍会传给模型；切换 Chat 不会抹去之前已经读入的项目内容，需要完全独立的讨论可使用“新对话”。

新对话不必选择项目，会创建专用的本地对话目录。项目模式保留原有会话结构。执行中或等待审批时，执行设置与模型切换被锁定；审批续跑使用任务保存的参数。

## 联网搜索

使用 DDGS 9.16 系列，指定 DuckDuckGo 后端，默认关闭。输入框地球按钮与软件设置均可切换。

- 搜索请求从客户端电脑访问外部搜索服务；模型推理仍走局域网主机。
- 开启后，模型可生成并提交搜索词；不会自动上传整个项目，提示词明确禁止发送密钥和私有文件内容作为搜索词。
- 返回标题、摘要与来源 URL，对话下方可点击来源在系统浏览器中打开。不提供网页全文抓取或自动浏览器操作。
- 搜索结果作为不可信资料处理；网络失败或限流返回明确错误，不当作“没有结果”。
- 每次 1–10 条结果可调。能否访问搜索服务取决于各客户端自己的网络。

## 参数设置与软件设置

参数设置：Temperature、Top P、最大输出 Tokens、最大模型步骤、请求超时。参数经校验后保存到本机，下一次模型请求生效；不同模型的实际支持能力仍取决于主机配置。

软件设置：深色/浅色/跟随系统、字体大小、发送快捷键、联网开关与搜索结果数。连接设置继续单独管理局域网地址和客户端 Virtual Key。模型列表仍自动从主机获取。

新增 API：`GET/PUT /v1/preferences`、`POST /v1/chat`。原有接口与认证机制继续保留，OpenAPI schema 随源码更新。

## 验证说明

测试结果：**45 passed / 2 skipped**。冻结程序自检确认本机 API、界面、新图标和 DDGS DuckDuckGo 引擎均可加载，且不包含开发者密钥。

回归覆盖模式权限、禁止伪造工具写入、参数边界与请求传递、偏好保存、审批跨重启、搜索开关及来源过滤，以及原有 sandbox、命令审批和任务停止流程。真实 DDGS 搜索已返回 Python 官方文档来源。界面验收使用隔离演示项目和确定性模型，不代表已逐一验证主机上的所有模型。

Windows 沙箱的 DPAPI 与符号链接集成仍受环境限制，正式安装和原生窗口升级请在正常用户桌面验收。既有加密密钥保留原来的 CurrentUser DPAPI 保护方式。
