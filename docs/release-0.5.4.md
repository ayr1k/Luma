# Luma 0.5.4

关闭旧版窗口与后台服务，运行安装包覆盖升级，原有项目、对话与设置保留。

## 帮助菜单

左下角设置图标上方新增同为 36×36 的帮助按钮。点击可选择“说明书”或“更新日志 · Change log”，内容在应用内打开，无需联网。菜单支持方向键选择、Escape 和点击外部关闭。

## 文件预览

项目文件查看器新增语法高亮、固定行号栏、语言及预览行数信息和自动换行。支持 Python、JavaScript、JSON、HTML 等常见语言；未知扩展名退回纯文本。深浅色主题分别使用适配配色。

文件仍为只读预览，不运行文件内的脚本。高亮完全在本机进行。超过 100000 字符或 3000 个换行的预览关闭高亮；原有文件读取限制与 workspace sandbox 保留。

## 验证

74 项测试通过，2 项受 Windows 沙箱限制跳过。覆盖源代码完整性、换行与空文件、未知格式、危险 HTML 作为文本呈现、大文件降级，以及既有功能。页面验证帮助菜单、内置文档与代码行号高亮。

安装包未代码签名。冻结程序检查包含语法高亮依赖；凭据加密自检仍受本机测试沙箱限制（系统错误 2），与旧版一致。普通 Windows 桌面的覆盖安装仍需实际环境验收。
