# Local Agent 0.3.0 预览版

## 升级

关闭已有 Local Agent 窗口及旧 API/Streamlit 进程，再运行 `LocalAgent-Setup-0.3.0-preview.exe`。安装目录与 0.2.0 相同，可以覆盖升级。项目列表、会话和加密连接配置仍位于 `%LOCALAPPDATA%\LocalAgent`，升级不覆盖这些文件，也不删除项目文件。

没有安装器需求时，解压 `LocalAgent-Portable-0.3.0-preview.zip` 并运行其中的 `LocalAgent.exe`。不要仅复制 exe，旁边的 `_internal` 目录也需要保留。

## 本次变化

- **任务进度**：发送任务后立即返回，不再等待整个任务完成才刷新页面。界面显示模型步骤、累计工具调用、最新完成的工具结果，并更新对话。
- **停止后续执行**：停止请求不会强杀正在执行的终端程序。当前模型请求或命令返回后，Core 跳过尚未执行的工具，并将状态记为“已停止”。已完成的文件修改保留，可继续查看 diff 或回滚。停止后可以发送下一条任务。
- **审批续跑**：批准/拒绝命令后也通过后台任务继续，保留一次性审批 ID 和后续工具队列，重复审批不会重复执行命令。
- **恢复进度**：暂时通信失败时显示“恢复进度”，重新读取同一任务，不重新发送任务或命令。服务重启后任务句柄失效，应重新打开项目查看会话；中断任务仍需核对文件并新建会话。
- **多开保护**：桌面、API、CLI 和旧 Streamlit 共用数据目录的操作系统锁，防止两个进程同时写同一套会话。不同数据目录仍不能安全地并发修改同一个工作项目，请勿同时操作同一项目。
- **Windows 保存冲突修复**：会话读取和原子替换使用短时存储锁，避免进度刷新与会话保存互相干扰；短暂文件占用会重试。持续保存失败时返回明确错误，不继续执行工具。
- **连接提示**：分别说明密钥失效、模型无权限、接口/模型不存在、限流、超时和主机连接失败，不返回服务端原始错误正文或密钥。

本次是按模型回复/工具执行步骤刷新，不是逐字流式输出。后台一次运行一个任务；等待审批时继续使用“允许执行”或“拒绝”。安装包仍未代码签名。

## API 增量

所有接口仍需本机令牌。旧同步 messages/approvals 接口保留。

| 方法与路径 | 作用 |
|---|---|
| `POST /v1/projects/{id}/tasks` | 提交 `{content}`，返回 202 和任务快照 |
| `POST /v1/projects/{id}/approval-tasks` | 提交 `{approval_id,allow}`，后台续跑 |
| `GET /v1/tasks/{task_id}` | 返回 running、cancel_requested、session、可选 error |
| `POST /v1/tasks/{task_id}/cancel` | 请求在安全边界停止后续执行 |

会话新增 `cancelled` 状态。运行中读取 session 不会将其误判为 interrupted。任务句柄只保存在当前服务内存中；会话与审批仍保存在磁盘。

## 验证记录

- 用户已确认 **0.2.0 在正常 Windows 桌面能打开窗口**；0.3.0 继续使用同一 WebView2 窗口方案。
- Python 回归：**31 passed / 2 skipped**。跳过 Windows 符号链接和当前沙箱用户 DPAPI 集成；未将这些环境限制当作通过。
- 实际本机 HTTP API + Edge 界面端到端通过：发起后台任务、显示审批、批准固定 echo 命令、完成任务、发起另一个任务并停止。
- 文件验证：允许的修改存在；停止后模型返回的写文件请求没有执行。
- 验证了审批防重放、命令执行期间停止、停止后继续会话、运行中读取快照、拒绝并发写入、持续磁盘错误和连续读写会话。
- 安装和原生窗口的自动化验收仍受当前测试环境限制。本版需在正常 Windows 用户桌面完成升级验收，不能把上版打开成功的反馈当成本版安装验收。

首次配置、环境要求及密钥保存方式见 `release-0.2.0.md`。
