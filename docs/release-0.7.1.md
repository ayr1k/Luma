# Luma 0.7.1

- 项目搜索与状态筛选对齐，归档入口保留独立边框和选中状态。
- 项目与任务列表重新设计：项目分组、数量标记、任务卡片、状态圆点，以及强调色选中边框。
- 文件预览空状态统一应用字体与缩进；取消文件选择后正确清空旧代码。
- Chat / Plan / Work 改用向上展开的菜单，与模型菜单风格一致，支持方向键、Enter、Esc。
- Skills、插件、附件和联网按钮增加清晰圆角边框，联网开启状态仍单独高亮。

完全退出托盘中的旧版 Luma 后覆盖安装。项目、对话、配置及已安装扩展继续保留。本版未修改预置扩展包，兼容范围仍为 0.7.x，无需因本次更新重新授权。

验证：166 项自动测试通过，2 项环境限制跳过；深浅色界面、任务筛选、模式菜单键盘操作、文件预览完成验证。冻结包 API、插件进程、预置插件、附件依赖通过自检。当前测试环境的 Windows 凭据存储自检仍返回错误 2，与上一版一致，未在本轮验证普通桌面的密钥保存。
